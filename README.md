## 📌 Descripción General

Esta bóveda académica contiene la estructura completa del semestre 2026-2 del programa de **Ingeniería de Software** en la **Universidad de Cartagena (UDC)**: apuntes por unidad, registro de entregas, horario y roadmap de actividades.
