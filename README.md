## 📌 Descripción General

Esta bóveda académica contiene la estructura completa, plan de estudio, cronogramas de 16 semanas, recursos bibliográficos, plantillas de protocolos e instructivos evaluativos para el primer semestre del programa de **Ingeniería de Software** en la **Universidad de Cartagena (UDC)**.

Está optimizada tanto para visualización dinámica en **Obsidian** como para navegación web estructurada en **GitHub**.
