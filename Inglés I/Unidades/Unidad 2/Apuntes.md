## 🧭 Unit Overview

This unit covers **shopping, markets, and commerce vocabulary** alongside the grammar of **comparative and superlative adjectives**, **there is / there are**, and **countable/uncountable nouns**. You will be able to describe markets, compare products, and talk about quantities.

**Core Topics:**
- Comparative and superlative adjectives
- There is / there are (affirmative, negative, interrogative)
- Countable and uncountable nouns
- Some / any / a lot of / many / much
- Vocabulary: Food, drinks, shopping, markets, prices

## 1. Comparative and Superlative Adjectives

### 1.1 Formation Rules

| Adjective Type | Comparative | Superlative | Example Adj. |
|:---|:---|:---|:---|
| **1 syllable** | + **er** | + **est** | cheap → cheaper → cheapest |
| **1 syl., CVC ending** | Double consonant + **er** | Double + **est** | big → bigger → biggest |
| **1 syl., ends in -e** | + **r** | + **st** | nice → nicer → nicest |
| **2 syl., ends in -y** | -y → **ier** | -y → **iest** | busy → busier → busiest |
| **2+ syllables** | **more** + adj | **most** + adj | expensive → more expensive → most expensive |
| **Irregular** | See table below | See table below | — |

### 1.2 Irregular Comparatives and Superlatives

| Adjective | Comparative | Superlative |
|:---:|:---:|:---:|
| good | better | best |
| bad | worse | worst |
| far | farther / further | farthest / furthest |
| little | less | least |
| many / much | more | most |

### 1.3 Using Comparative Adjectives

**Structure:** `Subject + verb + comparative adjective + than + second element`

```
This market is bigger than the supermarket.
Apples are cheaper than mangoes at this stand.
The local market is more traditional than the mall.
Colombian coffee is better than instant coffee.
```

> ⚠️ **Error common:** Usar doble comparativo: ~~"more cheaper"~~ → solo "cheaper". Los adjetivos cortos no usan *more*.

### 1.4 Using Superlative Adjectives

**Structure:** `Subject + verb + the + superlative adjective + (in/of/at…)`

```
This is the cheapest market in the city.
The mango is the most popular fruit at this stand.
It's the best price I've seen today.
```

### 1.5 Equality — As…as

```
This market is as big as the supermarket downtown.
Oranges are not as expensive as strawberries.
```

## 2. There is / There are

### 2.1 Form

| Type | Singular | Plural |
|:---|:---|:---|
| **Affirmative** | There **is** a bakery. | There **are** many stalls. |
| **Negative** | There **isn't** a pharmacy. | There **aren't** any benches. |
| **Interrogative** | **Is there** a cash register? | **Are there** any ATMs? |
| **Short answers** | Yes, there is. / No, there isn't. | Yes, there are. / No, there aren't. |

### 2.2 Context: Describing a Market

```
There is a large fruit section in the middle of the market.
There are about twenty vegetable stands near the entrance.
There isn't a parking lot, but there are bus stops nearby.
Are there any free samples? — Yes, there are at the cheese stand.
```

## 3. Countable and Uncountable Nouns

### 3.1 The Difference

| Type | Definition | Examples |
|:---|:---|:---|
| **Countable** | Can be counted; has singular and plural | apple/apples, egg/eggs, bottle/bottles |
| **Uncountable** | Cannot be counted; no plural form | water, rice, sugar, milk, coffee, bread, money, information |

> ⚠️ **Error común:** "I need some informations" → ❌. *Information* es incontable: "I need some information."

### 3.2 Quantifiers

| Quantifier | With Countable | With Uncountable | Context |
|:---|:---:|:---:|:---|
| **some** | ✅ (affirmative) | ✅ (affirmative) | some apples, some water |
| **any** | ✅ (neg./interr.) | ✅ (neg./interr.) | any oranges?, any milk? |
| **many** | ✅ | ❌ | many customers |
| **much** | ❌ | ✅ | much sugar |
| **a lot of** | ✅ | ✅ | a lot of fruits, a lot of rice |
| **a few** | ✅ | ❌ | a few coins (poca cantidad) |
| **a little** | ❌ | ✅ | a little salt (poca cantidad) |
| **no** | ✅ | ✅ | no products, no water |

```
There are many fruit stands in this market.       (countable)
There isn't much sugar left on that shelf.         (uncountable)
I have a few dollars but not much money.           (few=countable, much=uncountable)
```

## 5. Writing Model — Market Description

**Task:** Write 5-8 sentences describing a market using *there is/are*, comparatives, and food vocabulary.

**Model text:**
> The Paloquemao Market in Bogotá is one of the most famous markets in Colombia. It is bigger and more colorful than a regular supermarket. There are hundreds of stalls selling fresh fruits, vegetables, and flowers. The prices are lower than in most shopping malls, and the produce is much fresher. There is always a lot of noise and activity, especially in the morning. You can find exotic fruits like lulo, maracuyá, and tomate de árbol that aren't available in regular stores. It is the best place to experience Colombian food culture.

## 6. Errores Comunes de Hispanohablantes

| Error | Incorrecto | Correcto | Explicación |
|:---|:---|:---|:---|
| More con adj. cortos | *"more cheap"* | *"cheaper"* | Adj. cortos no usan *more* |
| Than vs. then | *"bigger then"* | *"bigger than"* | *Than* para comparación; *then* es "luego" |
| Much con contables | *"much apples"* | *"many apples"* | *Much* solo con incontables |
| Many con incontables | *"many informations"* | *"much information"* | *Many* solo con contables |
| Omitir *the* en superlativo | *"It is best market"* | *"It is the best market"* | El superlativo siempre lleva *the* |
| *There is* con plurales | *"There is many stands"* | *"There are many stands"* | Plural → *there are* |
| *Some* en negativas | *"There isn't some milk"* | *"There isn't any milk"* | Negativas usan *any*, no *some* |

## 9. Quick Reference

```
COMPARATIVES:
Short adj: + er (cheaper, bigger, nicer)
Long adj:  more + adj (more expensive, more popular)
Irregular: good→better, bad→worse

SUPERLATIVES:
Short adj: the + est (the cheapest)
Long adj:  the most + adj (the most expensive)
Irregular: good→the best, bad→the worst

THERE IS / THERE ARE:
Singular: There is a... / There isn't a... / Is there a...?
Plural:   There are... / There aren't any... / Are there any...?

SOME / ANY:
Affirmative: some (I have some apples.)
Negative:    any  (I don't have any apples.)
Question:    any  (Do you have any apples?)

COUNTABLE → many / a few / some / any
UNCOUNTABLE → much / a little / some / any
```
