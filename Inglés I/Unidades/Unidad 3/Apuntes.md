## 1. Passive Voice

### 1.1 Why We Use Passive Voice

In the **active voice**, the subject performs the action:
> *Google **develops** many apps.*

In the **passive voice**, the subject receives the action (the doer may be unknown or less important):
> *Many apps **are developed** by Google.*

**Use passive voice when:**
- The agent (doer) is unknown: "The file was deleted."
- The agent is obvious: "He was arrested." (by the police)
- The action is more important than the agent: "The software is updated every week."
- Writing in a formal/academic style

### 1.2 Structure

`Subject + be (conjugated) + past participle + (by + agent)`

### 1.3 Present Simple Passive

| Active | Passive |
|:---|:---|
| Google *updates* the app. | The app **is updated** by Google. |
| Engineers *design* the system. | The system **is designed** by engineers. |
| People *use* smartphones everywhere. | Smartphones **are used** everywhere. |

**Structure:** `Subject + am/is/are + past participle`

```
Active:  The developer writes the code every day.
Passive: The code is written every day (by the developer).

Active:  Students use this platform to submit homework.
Passive: This platform is used to submit homework (by students).
```

### 1.4 Past Simple Passive

**Structure:** `Subject + was/were + past participle`

| Active | Passive |
|:---|:---|
| Tim Berners-Lee *invented* the World Wide Web. | The World Wide Web **was invented** by Tim Berners-Lee. |
| Hackers *attacked* the system. | The system **was attacked** by hackers. |
| Workers *built* the first computers in the 1940s. | The first computers **were built** in the 1940s. |

```
Active:  They launched the app in 2020.
Passive: The app was launched in 2020.

Active:  Scientists discovered a new algorithm.
Passive: A new algorithm was discovered (by scientists).
```

### 1.5 Negative Passive

```
Present: The data is NOT stored on local servers.
Past:    The bug was NOT fixed before the release.
```

### 1.6 Interrogative Passive

```
Present: Is this software updated regularly?
Past:    Was the file deleted by accident?
         When was the internet invented?
```

## 3. Advantages and Disadvantages — Technology

### Writing Model: Technology in Society

**Task:** Write 5-8 sentences about the advantages and disadvantages of technology using passive voice.

**Useful phrases for advantages/disadvantages:**

```
ADVANTAGES:
One advantage is that… / A major benefit is…
Technology allows people to… / It is used to…
...can be accessed easily / ...is made faster by

DISADVANTAGES:
On the other hand… / However…
A major problem is… / One drawback is…
...can be misused / ...is often hacked / privacy is not always protected
```

**Model text:**
> Technology has transformed daily life in many ways. Information can now be accessed from anywhere in the world through the internet. Many services, such as banking and shopping, are now offered online. However, personal data is sometimes collected and sold without the user's knowledge. Social media platforms are used daily by billions of people, but they are also criticized for spreading fake news. Cybersecurity measures are developed constantly to protect users. Despite the risks, technology is considered one of the most important tools of the 21st century.

## 4. Errores Comunes de Hispanohablantes

| Error | Incorrecto | Correcto | Explicación |
|:---|:---|:---|:---|
| Usar active cuando corresponde passive | *"The code writes every day"* | *"The code is written every day"* | Verificar si el sujeto recibe la acción |
| Omitir el verbo *be* en la pasiva | *"The app updated"* | *"The app was updated"* | La pasiva siempre necesita *be* conjugado |
| Usar participio sin *be* | *"The file deleted yesterday"* | *"The file was deleted yesterday"* | *was/were* es obligatorio en pasiva pasada |
| Confundir past simple y past participle | *"The app was wrote"* | *"The app was written"* | Usar el participio pasado correcto |
| "I make a photo" | *"I make a photo"* | *"I take a photo"* | En inglés, las fotos se *take*, no *make* |
| "I opened the computer" | *"I opened the computer"* | *"I turned on / switched on the computer"* | Las computadoras se *turn on* |

## 7. Quick Reference

```
PASSIVE VOICE STRUCTURE:
Subject + be + past participle (+ by + agent)

PRESENT SIMPLE PASSIVE:
is/are + past participle
"The code IS WRITTEN by the team."
"Apps ARE DEVELOPED for smartphones."

PAST SIMPLE PASSIVE:
was/were + past participle
"The virus WAS DETECTED by the antivirus."
"The files WERE DELETED accidentally."

INTERROGATIVE:
Is the data stored securely?
Was the system hacked?
When was the internet invented?

KEY IRREGULAR PARTICIPLES:
write → written
build → built
make → made
send → sent
find → found
```
